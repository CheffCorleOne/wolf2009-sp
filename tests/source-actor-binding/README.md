# Source actor binding checks

The portable test exercises owning selected compiled entity/model preparation,
explicit four-role resources, exact logical animation selection, the bounded
readonly request/capability wire, retained frame1 sound commands, and the native
millisecond source-duration cycle coordinate. It refuses unknown tree profiles,
selected explicit trees, unsupported commands, inconsistent epochs and malformed
wire data. No renderer, entity, audio mixer or original executable is launched.

Build this directory with CMake and run CTest. Optional
`WOLF2009_SOURCE_ACTOR_SP_BASE` reads the owner's original archives without
modifying them, applies the explicit observed seven-step English startup subset,
and prepares the original locker binding. The resources and rig names in that
test are explicit selections, not a general declaration-to-packet inference.

The native implementation is compiled separately with
`WOLF2009_SOURCE_ACTOR_CORE` or `WOLF2009_SOURCE_ACTOR_GAME`; private C++ objects
never cross API8. The virtual request is lowercase hex, bounded to 32 KiB before
encoding. A returned readonly capability owns all source mount leases. Game
binding checks the existing V2 descriptors and native identities before creating
an immutable ordinary native animation set. Authored sounds require separately
qualified owning sound bindings. Geometry/animation caches follow normal native
manager lifetime; a native allocation failure can leave unused caches, but cannot
publish a partial actor binding.

The actor profile does not implement interaction, persistence, loot, AF, arbitrary
blend trees, arbitrary frame commands, source playback-rate changes, extraction,
or automatic ENTS frame interpretation. Source `ragdoll` and `af_pose` facts stay
retained without inferring that AF is active. Missing trees refer only to the
selected namespace and require the caller's explicit default SingleKeyframe
profile. The native source clock is an explicit millisecond visual policy,
not a claim of bitwise retail clock equivalence.
